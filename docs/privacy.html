What we process, and why

  • Your IP and basic request data are processed transiently by our infrastructure providers to deliver the page and protect it against abuse. Legal basis: legitimate interest (Art. 6(1)(f) GDPR). We do not store this data.
  • Page-view statistics with Umami, an open-source tool, on an instance run by the publisher at umami.edge99.net: no analytics company receives the data. For each page view the script sends the page address (including any query string, such as UTM tags), page title, referring page, browser, operating system, device type, screen size and browser language. From your IP address the server derives the country, region and city, and a session identifier computed with a one-way hash. The IP address itself is not stored. The data is not combined with other sources and is used only to see which pages are read. Legal basis: legitimate interest. The statistics are kept until deleted; database backups for 14 days.
  • No tracking pixels, no advertising.
  • No accounts, no forms, no newsletter on this marketing site.

Cookies & device storage

This site sets no cookies and stores nothing on your device. No cookie-consent banner is required.

The statistics script only reads one localStorage key, umami.disabled: if it is set, nothing is sent. To opt out in this browser, open the developer console on this site and run localStorage.setItem('umami.disabled', '1').

Processors & international transfers

  • GitHub, Inc. (USA) — static hosting (GitHub Pages).
  • Name.com, Inc. (USA) — domain registration and authoritative DNS only; it does not serve this site's content.
  • Cloudflare, Inc. (USA) forwards the statistics requests to the Umami instance, so it sees your IP address in transit. It does not serve this site's pages.

Serving the site transfers technical data (such as your IP) to the USA, covered by the providers' DPAs and the EU–US Data Privacy Framework / Standard Contractual Clauses.
