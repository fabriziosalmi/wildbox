# Does a set of API-key scopes satisfy the scope a request requires?
#
# One line for each pair: <granted> <required> <allow|deny>. <granted> is a
# comma-separated set of scopes, or "-" for a key that holds none.
#
# The gateway decides (scopes_satisfy in nginx/lua/auth_handler.lua) and the
# services check again on the scopes the gateway forwards (scope_satisfied
# in open-security-shared/scopes.py, #637). The two must agree: a service
# stricter than the gateway refuses a key the gateway let through, and a
# looser one is no second check. Both are tested against this table: the
# gateway on the wire by test/scope_vector_tests.sh, the shared package by
# tests/shared/test_scopes.py. Change the hierarchy in both, and here.
#
# Every scope identity grants (VALID_API_KEY_SCOPES), "*" and four sets,
# against every scope a route requires.
